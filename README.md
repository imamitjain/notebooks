## Quick Start

**Google Colab** — click any Colab badge above, then *Runtime → Run all*. Dependencies install automatically.

**Local** — run the one-time setup, then start Jupyter:

```bash
./setup.sh              # creates micromamba env, installs deps, registers kernels
micromamba activate p3
jupyter notebook
```
